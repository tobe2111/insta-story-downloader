# 실시간 시세 붙이기 — 사장님이 하실 일

무료 선에서 가장 신선한 시세를 쓰기 위한 설정입니다. **아무것도 안 하셔도
사이트는 그대로 돌아갑니다** — 그때는 야후 무료 시세로 내려가고, 화면이
스스로 "지연"이라고 표시합니다.

---

## 지금 상태 (설정 전)

| 자산 | 소스 | 신선도 |
|---|---|---|
| 코인 | 바이낸스 WebSocket | **체결 즉시** (설정 불필요) |
| 미국주식 | 야후 무료 | 장중 15초 갱신 · 야후 자체 지연 |
| 한국주식 | 야후 무료 | 장중 15초 갱신 · **약 20분 지연** |
| 원/달러 | 야후 `KRW=X` | 장중 15초 갱신 |

## 설정 후

| 자산 | 소스 | 신선도 |
|---|---|---|
| 코인 | 바이낸스 WebSocket | 체결 즉시 |
| 미국주식 | Finnhub 무료 | **실시간** |
| 한국주식 | 한국투자증권 | **실시간** |
| 원/달러 | 야후 `KRW=X` | 15초 (충분합니다 — 환율은 초 단위로 볼 이유가 없습니다) |

---

## ① 한국투자증권 (한국주식 실시간)

무료이고 공식 API입니다. 한국주식 실시간 시세를 무료로 주는 곳은 사실상
여기뿐입니다(네이버·다음 주소는 비공식이라 쓰면 안 됩니다).

1. 한국투자증권 계좌를 엽니다 (비대면 개설 가능)
2. **KIS Developers** (`apiportal.koreainvestment.com`) 에서 앱 신청
3. **앱키(App Key)** 와 **앱시크릿(App Secret)** 을 받습니다
4. Cloudflare 대시보드 → Workers → `quant` → Settings → **Variables and
   Secrets** 에서 아래 두 개를 **Secret** 으로 추가합니다

   ```
   KIS_APP_KEY      = (발급받은 앱키)
   KIS_APP_SECRET   = (발급받은 앱시크릿)
   ```

5. 저장하면 끝입니다. 배포도 코드 수정도 필요 없습니다 — 워커가 키가
   있는지 보고 스스로 실시간 소스로 갈아탑니다.

> ⚠️ 이 키는 **저장소에 절대 넣지 않습니다.** Cloudflare 시크릿에만
> 존재하고, 코드에는 `env.KIS_APP_KEY` 라는 이름만 있습니다. 검사
> (`test_no_credentials_are_committed`)가 키가 코드에 박히는 것을 막습니다.

> 모의투자 계좌로도 됩니다. 다만 모의 도메인은 유량 제한이 더 빡빡합니다.

## ② Finnhub (미국주식 실시간)

1. `finnhub.io` 무료 가입 → API 토큰 발급 (분당 60회)
2. 같은 자리에 Secret 추가

   ```
   FINNHUB_TOKEN = (발급받은 토큰)
   ```

안 하셔도 됩니다 — 미국주식은 야후도 비교적 신선합니다. 한국주식만큼
차이가 크지 않습니다.

---

## 설정이 됐는지 확인하는 법

사이트를 열고 **맨 위 시세띠**를 보십시오.

- 한국주식 뒤에 `실시간` → KIS가 붙었습니다
- `지연 시세` → 아직 야후입니다 (키가 없거나, 키가 틀렸거나, KIS가 응답을
  안 했습니다)

잔고 표 아래 문장도 같이 바뀝니다 — "모든 보유 종목이 **실시간** 시세입니다"
또는 "실시간 N종목 · 지연 M종목".

**라벨은 코드에 박혀 있지 않습니다.** 워커가 어느 소스로 받았는지를 응답에
실어 보내고 화면은 그 값을 읽을 뿐이라, 실시간 소스가 죽은 날에는 화면이
스스로 "지연"으로 바뀝니다. (감사 229에서 정확히 그 반대 상황 — 라벨은
'준실시간'인데 요청이 매번 거부당하고 있던 것 — 을 겪고 만든 규칙입니다.)

## 조종석(`python -m quant web`)에서도 쓰려면

조종석은 판정 사다리를 **다시 만들지 않고** 배포된 워커로 넘깁니다. 기본값이
이미 배포 주소라 대개 그대로 됩니다. 다른 주소를 쓰신다면:

```bash
export QUANT_QUOTES_URL="https://<내-워커-주소>/api/quotes"
python -m quant web --open
```

주소를 비우면 조종석은 확정값만 보여줍니다 — 못 받은 값을 옛 시세로 채워
'실시간'이라 쓰지 않습니다.

---

## 비용 — 전부 무료 한도 안입니다

- Cloudflare Workers 무료: **10만 요청/일**
- 워커는 심볼을 정렬해 캐시하므로, 보는 사람이 몇 명이든 **상류 호출은
  3초에 한 번**입니다(실시간 소스가 켜졌을 때)
- 브라우저는 **장중 · 탭이 보일 때만** 부릅니다 → 뷰어당 하루 약 3,100회
- 코인은 브라우저가 바이낸스에 직접 붙으므로 **워커 비용 0**

즉 동시 시청자 30명 정도까지는 무료 한도 안에서 돕니다. 그 이상 늘면
`STOCK_MS_OPEN`(장중 갱신 주기)을 올리면 됩니다 — 검사가 그 숫자와 화면
문구를 함께 묶어 두었으니 한쪽만 바뀌는 일은 없습니다.

---

## 바뀌지 않는 것

**판단·체결·기록은 여전히 새벽 확정 봉만 씁니다.**

실시간 시세는 *보여주기* 위한 것이고, 수익률·최대낙폭·TWR·킬스위치는 전부
장부의 확정값으로 계산됩니다. 이유는 두 가지입니다.

1. 평가액이 초 단위로 흔들리면 낙폭도 초 단위로 흔들리는데, 브레이크
   (킬스위치)는 새벽에 한 번만 돕니다 — 화면과 브레이크가 다른 숫자를
   보게 됩니다
2. "같은 데이터로 같은 결정을 재현한다"는 이 제품의 핵심 주장이 검산
   불가능해집니다

그래서 화면은 확정값을 주(主)로 놓고, 그 **아래에** '지금' 값을 따로
적습니다. 두 숫자가 다른 것은 정상이며, 어느 쪽이 무엇인지 화면이 항상
밝힙니다.
